# Manifiesto de revisión — Fase 1.6

El paquete `restaurant-os-fase-1.6-revision.zip` contiene el comando de integración, los fixtures y pruebas de `apps/api/test/`, documentación de `docs/testing/`, y las actualizaciones de estado/pendientes.

Excluye `.env` privados, tokens, contraseñas, certificados, bases, respaldos, `node_modules`, `dist`, cachés, binarios y referencias visuales privadas. El SHA-256 se publica fuera del ZIP para evitar modificar el artefacto tras calcularlo.
