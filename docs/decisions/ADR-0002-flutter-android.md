# ADR-0002 — Flutter para Android móvil y tableta

**Estado:** APROBADO. Trazabilidad: ADR-004 en `docs/07-ADR.md`.

## Decisión

Flutter/Dart es obligatorio para `table_kiosk` y futuras aplicaciones de tableta/móvil. Android es el primer destino.

## Consecuencias

NFC, QR, modo kiosco y periféricos se resolverán con capacidades Android cuando el hardware esté aprobado. React no sustituye a Flutter en la tableta de mesa.
