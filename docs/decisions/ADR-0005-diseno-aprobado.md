# ADR-0005 — Diseño por etapas antes de UI productiva

**Estado:** APROBADO. Trazabilidad: ADR-005 en `docs/07-ADR.md`.

## Decisión

La Fase 0 precede a módulos operativos. Su identidad visual usa temas por entorno, tokens semánticos, accesibilidad y referencias reconstruidas que requieren validación explícita.

## Consecuencias

Esta entrega se detiene en Fase 0.1. Wireframes, arquitectura UX, prototipos y flujos operativos no se adelantan.
