# Referencias visuales internas

Este directorio contiene localmente cuatro PNG oficiales usados como fuente de verdad visual:

- `01-admin-aprobado.png`
- `02-tablet-aprobado.png`
- `03-kds-aprobado.png`
- `04-pos-aprobado.png`

Los binarios están excluidos de Git porque su uso interno como referencia no demuestra derechos de publicación o redistribución de sus marcas, personas, fotografías y demás contenido. No deben copiarse a releases, ZIP públicos ni historial Git hasta que el propietario aporte autorización verificable.

Los nombres, dimensiones y SHA-256 se conservan en `docs/design/REFERENCIAS-VISUALES.md`; excluir los archivos no cambia su carácter de fuente de verdad local.
